# Experiment Protocols

This directory contains pre-registrations, implementation contracts, and explicitly
marked exploratory drafts. Experiment executables remain one directory above so the
instrumentation build stays simple.

Before changing or implementing a protocol, read:

- `../../../SCIENTIFIC_METHOD_PROMPT.md`
- `../logs/TMIX_INVESTIGATION.md`
- the relevant completed result logs in `../logs/`
