relative-geometry null result. It is not a confirmation study and cannot
establish a depth trend.

the same registered relative-geometry-null comparison pattern as layer 15?

The classified layer-15 run rejected the registered incidental-relative-

same metric. These descriptive possibilities do not establish a depth trend.
