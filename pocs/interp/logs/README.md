# Scientific Logs

This directory is the durable record of what was measured, what failed, and what
remains unknown.

## Read First

`TMIX_INVESTIGATION.md` is the current investigation ledger. Read it before
proposing an interpretation or experiment.

## Result Logs

| Log | Scope |
| --- | --- |
| `TMIX_ROTOR_SUBSPACE_RESULTS.md` | Preliminary residual-relative tangent and ambient-addition tests |
| `TMIX_DESTINATION_SUBSPACE_RESULTS.md` | Layer-30 destination-subspace confirmation and replication |
| `TMIX_DESTINATION_SUBSPACE_PILE_EXPLORATORY_DEPTH_RESULTS.md` | Explicitly exploratory Pile layers 15, 30, 45, and 60 scan |

Result logs report observations under their stated model, backend, corpus, and
controls. They do not inherit stronger claims from later hypotheses.
